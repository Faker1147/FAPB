Crash fix (1.6)
  Symptom   : hl.exe crashes in fapb.dll at offset 0x18173 (c0000005)
  Cause     : FAPB loaded together with YAPB/SYPB/PODBot/EBot/CSBot
              and/or duplicate AMXX binaries. The bot-core hook chain is
              corrupted, so an FAPB runtime pointer stays NULL.
  Fix       : install_fapb.ps1 now comments out other bot cores and the
              duplicate amxmodx_bl_mm.dll; only FAPB stays active.
  Verified  : clean FAPB-only HLDS has the runtime pointer initialized;
              multi-bot plugins.ini reproduced the crash condition.

Notes
  - The original YAPB aim/shooting/behaviour code is unchanged.
  - Only plugin/cmd/cvar/path strings were renamed (binary-level fork).
  - The native main menu is fapb.dll's built-in menu, relabeled and bound
    to V. It is not a newly coded T/CT dashboard.
  - Only ONE bot core may be active at a time.
  - A brand-new T/CT dashboard inside fapb.dll would require rebuilding
    YAPB from source; this package does not do that.
