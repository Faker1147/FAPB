Notes

  - Only plugin/cmd/cvar/path strings were renamed (binary-level fork).
  - The native team menu reuses fapb.dll's built-in Control Menu and
    only changes the Chinese labels + V key bind.
  - A brand-new T/CT dashboard inside fapb.dll would require rebuilding
    YAPB from source; this package does not do that.
  - Do not load FAPB and YAPB/SYPB as active bot cores at the same time.
